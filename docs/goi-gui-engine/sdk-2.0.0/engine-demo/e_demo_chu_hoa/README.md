# e_demo_chu_hoa — Đổi văn bản thành chữ hoa (DEMO)

Engine DEMO tối giản, đặt ngoài Core: năng lực `van_ban.chu_hoa@1` nhận `van_ban` và trả `van_ban` đã viết hoa toàn bộ (giữ dấu tiếng Việt), dùng làm bước giữa của quy trình. Chỉ dùng SDK (`kho_tri_thuc_sdk`); chạy thử không cần Core: `python -m kho_tri_thuc_sdk.thu <thư mục này>` (ví dụ ở `chay_thu_demo`; văn bản mẫu `demo/mau.txt`). Chỉ dữ liệu DEMO.
