# e_demo_dem_tu — Đếm từ và dòng (DEMO)

Engine DEMO tối giản, đặt ngoài Core: năng lực `van_ban.dem_tu@1` nhận `van_ban` và trả `truong` gồm `so_tu`, `so_dong` (kiểu `so`), ghép được vào cột ngăn của module; ô Cài đặt bước `bo_dong_trong` (có/không, mặc định có) quyết định có tính dòng trống hay không. Chỉ dùng SDK (`kho_tri_thuc_sdk`); chạy thử không cần Core: `python -m kho_tri_thuc_sdk.thu <thư mục này>` (ví dụ ở `chay_thu_demo`; văn bản mẫu `demo/mau.txt`). Chỉ dữ liệu DEMO.
