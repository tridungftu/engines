# e_mask — DEMO

MASK-0 có khung SDK; MASK-1 thêm lõi so khớp thuần và bí danh `[[...]]`. Hai năng lực cổng vẫn trả `CHUA_LAM`, chưa hoàn tất che/mở che, chưa kích hoạt vận hành. Đã kiểm bằng Core giả (CoreGia).

Lõi trong `e_mask/nguon/privacy/` chỉ cần thư viện chuẩn. Không có mã hóa bảng hoặc xuất Word mới; detector/hậu kiểm đầy đủ ở MASK-2. Xem `NGUON.md` về nguồn, SHA và giới hạn. Linux dùng đường DEMO tường minh qua KTT_ENGINE_CAU_HINH.
